# CLAUDE.md

Antree is a 2D top-down satire game about getting one document from the
government of Kuvukiland, a fictional republic. Rust with macroquad 0.4. It
builds natively for development and to `wasm32-unknown-unknown` for the
browser. Design: `docs/GDD.md`. Code map and data flow: `docs/ARCHITECTURE.md`.
`AGENTS.md` is a symlink to this file. Edit `CLAUDE.md` only.

## Layout

| Path | What |
|------|------|
| `src/game/` | Pure game logic (meters, clock, quests, minigames, grades). Never imports macroquad. Unit tests live here |
| `src/scene/` | Scenes: title, quest select, overworld, office, minigames, ending, tutorial |
| `src/art.rs`, `src/ui.rs`, `src/fx.rs` | Sprite drawing, UI widgets, synthesized sound and screen shake |
| `src/save.rs` | localStorage (quad-storage): unlocks in `antree.save.v1`, a saved run in `antree.run.v1` |
| `assets/data/*.ron` | All player-facing text and tuning: offices, quests, dialog, forms, strings |
| `assets/sprites/` | Generated by `tools/sprites.py` (Pillow). Edit the script, not the PNGs |
| `web/` | `index.html`, `boot.js`, and the vendored macroquad JS plugins |
| `server/` | `antree-server`, a wasi:http component that embeds `dist/` and serves it |
| `build.sh`, `Dockerfile` | Build the component and the `FROM scratch` image |

## Commands

| Command | Does |
|---------|------|
| `make dev` | Run natively |
| `make web` | Build `dist/` (game wasm, page, assets) |
| `make serve` | Serve `dist/` on port 8080 |
| `make check` | `make words`, fmt, clippy (`-D warnings`, native and wasm), all tests, the same for `server/` |
| `make words` | Fail on banned real-world names. Run it after any text change |
| `make sprites` | Regenerate the sprite sheets |
| `./build.sh` | `make web`, then `antree-server.wasm` |

`make check` needs `dist/`, because the server tests read the embedded build.
Run `make web` first on a clean checkout.

## Rules

- In-game text is English. Proper nouns come from the Kuvukiland naming table
  in `docs/GDD.md`. Never use real country, region, agency, or official title
  names. `make words` enforces the list.
- Text a writer edits goes in `assets/data/`, not in code.
- Unit-test pure logic in `src/game/` and `src/save.rs`. No rendering tests.
- clippy clean with `-D warnings`. Run `cargo fmt`.
- No em dashes or en dashes anywhere: code, comments, docs, commits, strings.
- `docs/GDD.md` and `docs/ARCHITECTURE.md` stay under 2500 words each. Update
  If a module, a save key, or a scene transition changes, update
  ARCHITECTURE.

## Git

- Commit and push straight to `main`. No pull requests in this repo.
- Commits are GPG-signed. Conventional Commits (`feat:`, `fix:`, `docs:`).

## Verify in a browser

Tests do not cover drawing. After a visible change, check the real page:

1. `make web`, then `make serve`.
2. Start headless Chrome with `--remote-debugging-port=9222` and a new
   `--user-data-dir` for each build. Chrome caches the wasm, so a reused
   profile shows the old build.
3. Drive it over CDP (keys, clicks, screenshots) and look at the screenshots.
   Set the viewport to 1280x720 so the 640x360 canvas scales by 2.

Data files load at runtime, so you can edit `dist/assets/data` to force a
branch without a rebuild.

## Release and deploy

The game runs at <https://antree.franzramadhan.dev> on a homelab k0s cluster.
The pod runs `antree-server.wasm` under the runwasi wasmtime shim
(RuntimeClass `wasmtime`). The game itself runs in the visitor's browser.

1. Bump `version` in `Cargo.toml` and push to `main`.
2. Push a signed tag that matches: `git tag -s v0.1.1 -m v0.1.1 && git push origin v0.1.1`.
3. The `release` workflow runs `./build.sh` and `make check`, then pushes
   `ghcr.io/franzramadhan/antree:<version>` (`linux/amd64`).
4. In the homelab infrastructure repo, pin the new tag and digest in
   `kubernetes/apps/antree/deployment.yaml` through a PR. Flux applies it.
5. Check `https://antree.franzramadhan.dev/healthz` and play one screen.

Get the digest with
`gh api /users/franzramadhan/packages/container/antree/versions -q '.[0].name'`.

## Gotchas

- The shim serves WASI 0.2.6. `server/` pins `wasip2 = "=1.0.1"` and builds
  for `wasm32-wasip1` with the wasmtime 36 proxy adapter. If the component
  imports a newer WASI version, `build.sh` fails. Do not switch to
  `wasm32-wasip2`.
- The image must be `linux/amd64`. A `wasip1/wasm` platform image pulls but
  never unpacks on the nodes.
- The server sends a CSP with `script-src 'self' 'wasm-unsafe-eval'`. Inline
  scripts are blocked, so page scripts go in files under `web/` and in the
  `make web` copy line.
- Asset names do not change between builds. The server sends `no-cache` and
  one ETag per build, so browsers revalidate and get 304s.
- Cloudflare shows a bot check to curl and headless Chrome on the public
  host. Test the component locally: `wasmtime serve -C cache=n --addr
  127.0.0.1:8081 -Scli antree-server.wasm`.
- The macroquad `audio` feature is required for sound. Browsers unlock audio
  on the first key press or click.
- `sapp-jsutils` and `quad-storage` JS files are vendored and pinned. The
  wasm linker gets `--allow-undefined` from `.cargo/config.toml`.
